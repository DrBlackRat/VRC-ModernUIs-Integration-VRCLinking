# What is the ModernUIs VRCLinking Integration?

Integration to allow using VRCLinking for ModernUIs Whitelist / Permission system.

### VRCLinking

Website: https://vrclinking.com/

GitHub: https://github.com/VRCLinking/VRCLinkingSDK

### ModernUIs

GitHub: https://github.com/DrBlackRat/VRC-ModernUIs

# How to use it

You can add the VRCLinking To Whitelist Bridge Prefab to your scene under:

`Tools > DrBlackRat > ModernUIs Integrations > VRCLinking`
